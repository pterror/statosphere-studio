# Content Rule Category

Which content stream this rule modifies:

- **Input** — rewrites the user's message before the bot sees it. The chat history shows the original.
- **Post Input** — adds a system note after input classifiers run. Visible to the user as a chat notice.
- **Stage Direction** — adds a hidden instruction to the bot's prompt. Never shown to the user.
- **Response** — rewrites the bot's reply before it is displayed. The user sees the modified version.
- **Post Response** — adds a system note after response classifiers run. Visible to the user after the bot's message.
