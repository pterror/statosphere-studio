# Classification Label

The word or phrase substituted into `{}` in the hypothesis template. This is what the NLP model scores against the input or response text.

Use clear, descriptive phrases that complete your hypothesis naturally. For example, with hypothesis `"This message expresses {} sentiment."`, good labels are `positive`, `neutral`, `negative`.

```
{ "label": "positive" }
{ "label": "taking damage" }
{ "label": "trying to move to a new location" }
```
