# Classifier Name

A unique label for this classifier, used in logs and as a reference when other classifiers or generators declare it as a dependency. Must be unique across all classifiers.

Choose a name that describes what the classifier detects — `UserSentiment`, `AttackDetect`, `LocationChange`. This name appears in the dependency field of any classifier or generator that must wait for this one.

[Learn more →](https://pterror.github.io/statosphere-guide/syntax/classifiers#name)
