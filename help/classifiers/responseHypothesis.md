# Response Hypothesis Template

The hypothesis template for classifying bot replies. Same format as the Input Hypothesis Template — the `{}` placeholder is replaced with each label.

Used only when Response Template is set. Lets you use a different hypothesis framing for response classification than for input classification.

```
"responseHypothesis": "The character expresses {} emotions."
"responseHypothesis": "The response describes a {} outcome."
```
