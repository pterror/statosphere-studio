# Include History

When enabled, recent chat history is included in the text generator's prompt for additional context. Increases token usage and response time.

Use this when the generator's output depends on what has been said — for example, a recap generator that summarizes recent events. Disable it when the prompt is self-contained and doesn't need conversation context.

[Learn more →](https://pterror.github.io/statosphere-guide/syntax/generators#includehistory)
