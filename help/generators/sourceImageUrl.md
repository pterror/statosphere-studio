# Source Image URL

For Image-to-Image generators: an expression that evaluates to the URL of the source image to transform.

```
"sourceImageUrl": "background"
"sourceImageUrl": "characterPortrait"
```

This is typically a variable name — a variable that previously received the output of an Image generator. The referenced variable should hold a valid image URL.

[Learn more →](https://pterror.github.io/statosphere-guide/syntax/generators#sourceimageurl)
