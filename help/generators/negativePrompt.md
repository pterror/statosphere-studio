# Negative Prompt

Content to exclude from the generated image. Describe things you do not want to see — the image model will try to avoid them.

```
"negativePrompt": "blurry, low quality, text, watermark"
"negativePrompt": "nsfw, extra limbs, deformed"
```

This field is only used for Image and Image-to-Image generators.

[Learn more →](https://pterror.github.io/statosphere-guide/syntax/generators#negativeprompt)
