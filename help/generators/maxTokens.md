# Maximum Response Tokens

The maximum number of tokens to request in the generated response. Default: `"250"`.

Keep this low for concise outputs like labels, short phrases, or one-sentence summaries. A recap generator might use `"80"`. A detailed description might use `"400"`. The value is a string expression.

[Learn more →](https://pterror.github.io/statosphere-guide/syntax/generators#maxtokens)
