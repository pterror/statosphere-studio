# Generator Type

What kind of content this generator produces:

- **Text** — sends a prompt to the chat LLM and stores the reply in a variable
- **Image** — generates an image from a text prompt using a diffusion model
- **Image-to-Image** — transforms an existing image using a source URL

Most generators are Text. Use Image when you want scene artwork or character portraits based on current state.
