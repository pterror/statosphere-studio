# Function Name

The name you use to call this function in any expression throughout the config. Unlike variable names, function names are case-sensitive: a function named `hpLabel` must be called as `hpLabel`, not `HPLabel`.

Pick something short and descriptive. Avoid names that clash with built-in mathjs functions (`min`, `max`, `floor`, etc.) or built-in Statosphere helpers (`split`, `join`, `contains`, etc.).

[Learn more →](https://pterror.github.io/statosphere-guide/syntax/functions#name)
