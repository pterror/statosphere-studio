# Pre-Response Update (Initial Response Update)

A formula whose result replaces this variable's value immediately when the bot's reply arrives, before response classifiers run.

Use this for variables that should reset or be set at the start of response processing — for example, clearing a flag so response classifiers can write to it fresh.

Leave blank if you do not need a pre-response update.
