# Variable Name

The identifier you use to reference this variable everywhere else in the config — in expressions, template tags like `{{hp}}`, classifier updates, and generator updates. Capitalization is ignored, so `HP` and `hp` resolve to the same variable.

Use simple names without spaces: `hp`, `mood`, `turnCount`, `currentScene`. Stick to letters, digits, and underscores to ensure the name works reliably as a template tag.

[Learn more →](https://pterror.github.io/statosphere-guide/syntax/variables)
