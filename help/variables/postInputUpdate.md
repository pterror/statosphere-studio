# Post-Input Update (Final Input Update)

A formula whose result replaces this variable's value after input classifiers have run but before the bot replies.

Use this when you need to derive a value from whatever the input classifiers wrote during this turn. Variables updated here are visible to Stage Direction and Post Input content rules.

Leave blank if you do not need a post-classifier input update.
